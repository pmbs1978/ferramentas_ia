Templates de Engenharia de Prompts

Prompt para Otimizar Outros Prompts

Use este modelo para analisar e reescrever um prompt existente, tornando-o mais claro, específico e eficaz. 

ROLE
És um engenheiro de prompts de classe mundial, especialista em otimizar instruções para LLMs como o Gemini e o Claude. A tua função é avaliar criticamente um prompt e reescrevê-lo para máxima clareza, especificidade e eficácia.

TASK
1. Analisa o "Prompt Original" abaixo.
2. Identifica os seus pontos fortes e fracos.
3. Reescreve o prompt, criando uma "Versão Otimizada" que seja significativamente melhor.

Prompt Original:
"""
[COLE AQUI O PROMPT QUE QUER MELHORAR]
"""

OUTPUT FORMAT
Apresenta a tua resposta em três secções claras:
1. Pontos Fortes: O que o prompt original faz bem.
2. Pontos a Melhorar: Onde o prompt falha em especificidade, contexto ou clareza.
3. Versão Otimizada: A nova versão do prompt.

Prompt de Persona

Use este modelo para instruir a IA a adotar uma persona específica, melhorando a relevância e o estilo da resposta. 

Aja como um [PROFISSÃO OU ESPECIALISTA], por exemplo, um programador sénior especialista em Python e Docker.
A sua tarefa é [DESCREVA A TAREFA PRINCIPAL], por exemplo, analisar o meu código e sugerir melhorias.
O seu público-alvo é [PÚBLICO-ALVO], por exemplo, um programador júnior com conhecimentos básicos de Linux.
O tom da sua resposta deve ser [TOM DESEJADO], por exemplo, amigável, pedagógico e profissional.
Use exemplos práticos para ilustrar os seus pontos.
Não use [ELEMENTOS A EVITAR], por exemplo, jargão demasiado complexo sem explicação.

Prompt para Resumir Texto

Ideal para extrair as ideias principais de um artigo ou documento. 

Resume o seguinte texto em 5 pontos principais (bullet points).
Cada ponto deve ser conciso e direto.
O objetivo é captar as ideias centrais para alguém que não tem tempo de ler o texto completo.

Texto a resumir:
"""
[COLE O TEXTO AQUI]
"""

Prompt para Geração de Artigos

Um modelo completo para gerar artigos personalizados, definindo tópico, público e objetivo. 

Você é um especialista em criação de conteúdo. Siga os seguintes passos:

ETAPA 1 – COLETA DE DADOS

Solicite as seguintes três informações ao usuário:
1. Tópico – Tema central do artigo.
2. Público-alvo – Quem vai ler o artigo? Ex: estudantes, empreendedores, etc.
3. Objetivo – O que o artigo deve fazer? Informar, ensinar, convencer, etc.

ETAPA 2 – ESTRUTURA DO ARTIGO

Com base nas informações, gere um artigo com:
- Título claro
- Introdução (tema, interesse, objetivo)
- Desenvolvimento (parágrafos organizados, subtítulos, exemplos)
- Conclusão (retomar pontos, reforçar objetivo, chamada para ação)
- Extensão: entre 800 e 1200 palavras.

ETAPA 3 – AJUSTE DE LINGUAGEM

Adapte a linguagem ao público-alvo:
- Estudantes: Clara, explicativa, com exemplos.
- Profissionais iniciantes: Didática, com analogias.
- Executivos: Direta, objetiva, com dados.
- Leitores leigos: Acessível, sem jargões.

ETAPA 4 – FORMATAÇÃO DO TEXTO

- Use títulos e subtítulos claros.
- Divida em parágrafos curtos.
- Utilize bullet points quando útil.
- Escreva com originalidade e evite repetições.

Prompt para Gerar Prompts de Trabalho

Um modelo interativo para que a IA ajude a criar prompts personalizados para as suas tarefas profissionais. 

# Persona
Atue como um Engenheiro de Prompts experiente.

# Tarefa
Criar 5 prompts de alta qualidade, importantes para meu trabalho.

## Instruções
1. Faça 5 perguntas para entender o que eu faço e que sejam relevantes para a criação de prompts.
2. Me pergunte sobre possíveis aplicações de LLMs no meu trabalho.
3. Escreva 5 prompts detalhados usando markdown e em janelas de código independentes.

# Verificação
Se você entendeu a tarefa, escreva "Entendi" e comece com a primeira pergunta.
## IMPORTANTE: Faça uma pergunta de cada vez. Só faça uma nova pergunta após receber a minha resposta

Prompt para Cópia Exata de Texto

Use este prompt para garantir que a IA devolva um texto exatamente como foi fornecido, sem qualquer alteração, ideal para preservar formatação e conteúdo original. 

## Instruções
Copia e devolve o texto exatamente como eu enviar, sem resumir, sem cortar e sem alterar nada. 
O texto deve ser devolvido palavra por palavra, na mesma ordem, com a mesma formatação, incluindo quebras de linha, espaços e pontuação. 
Não faças comentários, não faças interpretações, não expliques nada. 
Apenas devolve o texto integral dentro de um bloco de código (``` … ```).

Prompts para Desenvolvimento e Programação

Explicar Bloco de Código

Perfeito para quando encontra um código que não compreende totalmente. 

Aja como um professor de programação. Explique o seguinte bloco de código [LINGUAGEM, ex: PHP] linha por linha.
Descreva o que cada parte faz e qual o propósito geral da função/script.
No final, dê um exemplo prático de como este código poderia ser utilizado.

Código:
```php
[COLE O CÓDIGO AQUI]
```

Gerar Código com Requisitos

Use para criar snippets de código baseados em necessidades específicas. 

Escreva uma função em [LINGUAGEM, ex: JavaScript] que faça o seguinte:
1.  Receba um [TIPO DE INPUT, ex: array de números] como argumento.
2.  [REQUISITO 1, ex: Calcule a média de todos os números].
3.  [REQUISITO 2, ex: Retorne 0 se o array estiver vazio].
4.  Adicione comentários ao código para explicar a lógica.
5.  O código deve seguir as boas práticas da linguagem.
